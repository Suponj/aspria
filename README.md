# Aspria v0.2 — 資産の記録と、成長の軌跡。

個人利用向けの、ビルド不要・オフライン対応の資産記録PWAです。

## GitHub Pagesへの更新

既存の `aspria` リポジトリのルート（`index.html` が置かれている階層）に、**このZIPのファイルだけ**をアップロードしてください。以前の同名ファイルは上書きします。GitHub Pagesは今までの `main / (root)` 設定のままで構いません。

**注意：** `aspria.json` や実際の銀行残高を記載したExcelは、絶対にPublicリポジトリにアップロードしないでください。

## データの保存とバージョンアップ

- 口座・残高・入力途中のデータは、これまでと同じ端末のIndexedDB（`aspria-local`）に保持します。更新時に初期化する処理はありません。
- 新しいバージョンへ更新する前に、**設定 → JSONを書き出す** でバックアップしてください。
- Google Driveへ保存するのは、明示的に書き出したJSONファイルだけです。アプリ自体には自動同期機能はありません。
- 異なるURL・別ブラウザ・ブラウザのデータ消去後は、元の端末データが見えない場合があります。必要ならJSONを読み込んで復元してください。

## Excel（.xlsx）の取り込み

1. 設定 → 「Excel（.xlsx）を選択」で既存のExcelを指定します。
2. 最初の記録年月を指定します。対象のサンプルExcelは `2024-12` です。「12/e」「1/e」のような月のみの見出しから、年またぎを自動的に判断します。
3. 13口座について、口座名と4分類を設定します。既存のAspria口座と同じ場合は取り込み先に既存口座を選べます。
4. 取り込み方法を選びます。
   - **既存に追加：** 現在のデータを保ち、Excelからまだ記録していない残高を補います。同じ口座・年月に記録済み残高がある場合は、既存を優先します。
   - **すべて置き換える：** 現在のデータを削除し、Excelのデータで置き換えます。サンプルデータから実データに切り替える際はこちらが適切です。
5. 確認ダイアログで件数を確認します。現在のデータがある場合は、適用前に自動生成されるJSONバックアップを保存したことを確認してください。

### 対応するExcelの配置

- 口座・資産名：B4～B16
- 月の見出し：C3以降（`12/e` など）
- 月別残高：各口座の行と年月の列が交差するセル
- 17行目以降にある小計・計算式は読み込みません。
- 金額は0以上の円単位整数（`0`も記録済み）。空欄は「未記録」。見出しに列自体がない月は追加しません。
- 口座を開設していない期間は、取り込み後に各口座の「記録開始月・終了月」で調整してください。
- 現在のサンプルは最初のシートを対象とします。複数シートの選択機能や旧 `.xls` ファイルには未対応です。

**重要：** 記録月のうち一部の口座が未記録なら、Aspriaはその月を確定扱いせず、総資産グラフに不完全な合計値を載せません。

## セキュリティ・ライブラリ

- 取り込み処理はブラウザ内で完結し、ユーザーが選んだExcelの中身を外部へ送信するプログラムはありません。
- Excel解凍のために同梱する **JSZip v3.10.1** を使用します。MITライセンスに基づき、`JSZIP_LICENSE.txt` を添付しています。
- HTMLのCSPは `connect-src 'self'` で外部接続を制限しています。
- バックアップJSONは暗号化されていません。共有しないクラウドフォルダに保存し、誤公開に注意してください。
