# Aspria v0.3.0 — 資産の記録と、成長の軌跡。

個人の資産を月次で記録・分析する、軽量なオフライン対応PWAです。

## GitHub Pages への更新方法

1. **先に現行のAspriaから「設定 → JSONを書き出す」でバックアップ**してください。
2. このZIPを解凍し、11ファイルすべてをGitHubの公開リポジトリの**ルート**にアップロードします（ZIPそのものや上位フォルダではありません）。
3. 同名ファイルを更新してCommitします。GitHub Pages（main / root）の設定は変更不要です。
4. ブラウザでAspriaを開き直し、`Aspria v0.3.0` と表示されることを確かめます。旧版が出る場合はページを再読み込みしてください。端末の**サイトデータ削除は行わないでください**。

## v0.3.0 の新機能

- **月別の4分類の残高**：分析画面下部で年月を選べます。未記録口座がある月は「入力済み分の小計（未確定）」として明示します。
- **グラフ横軸**：日付の実際の月間隔に従って配置し、表示期間に応じた年月目盛りを追加しました。折れ線の点を押すと月別の内訳へ移動します。
- **金額非表示モード**：右上の丸いボタンで切り替えます。金額、増減額、入力欄を隠し、総資産／金融資産の推移を**基準値100の指数**で表示します。基準は選択期間中の各系列の最初の正の記録です。比率や相対的変化は公開されます。暗号化／アクセス制限ではありません。
- **JSONバックアップ名**：`aspria_YYYY-MM-DD_HHmm.json` の形式になります。
- **OS共有**：設定の「共有して保存」からAndroid/iPadの共有画面へJSONファイルを渡せます。Google Driveの受け入れ、保存先指定、既存ファイルの上書き可否はOS／アプリによります。未対応なら通常のダウンロードをご利用ください。Google認証やAPI連携は不要です。
- **Excel用CSV出力**：設定の「Excel用CSVを書き出す」で、年月・分類・口座・残高（円）・状態の縦長表をUTF-8 BOM付きで出力します。全期間（記録のない月も含む）を出力し、0円、未記録、入力途中、対象外を区別します。個人情報が含まれるため保存・共有には注意してください。

## 現行データの保持・安全性

- IndexedDBは従来の `aspria-local`、JSONは `version:1` のままです。**既存の記録を初期化しません**。
- 口座・残高は端末のブラウザ内に保存されます。GitHub Pagesへ資産の実データは送信しない設計です。
- JSON読み込みは現在のデータを置き換えます。別端末に移す場合は先にJSONでバックアップしてください。
- 公開GitHubには **実際のJSON/CSV/Excelの内容を絶対にアップロードしないでください**。
- Excel取り込みは引き続き、B4～B16が口座名、C3以降が年月、C4以降が残高の形式に対応します。途中で空欄がある場合も0円にはしません。
- Excel解凍には同梱の JSZip 3.10.1（MIT）が必要です。ライセンスは `JSZIP_LICENSE.txt` を参照してください。

## まず確認する操作

架空データで、(1)3種の分析グラフ、(2)月別内訳、(3)金額非表示、(4)CSV書き出しとExcel表示、(5)JSON書き出し／再読み込み、(6)共有メニューを確認してから実データをご利用ください。
